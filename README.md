# 🚀 Pagination Frontend (React.js)

A modern and responsive **React.js** frontend application that consumes the **Spring Boot Pagination REST API** to perform **CRUD operations** with advanced **Pagination**, **Sorting**, and **Search** functionality. The application provides an intuitive user interface for efficient data management and seamless interaction with large datasets.

---

## ✨ Features

- ➕ Create new records
- 📋 View all records
- ✏️ Update existing records
- ❌ Delete records
- 🔍 Search records by keyword
- ↕️ Dynamic Sorting (Ascending & Descending)
- ⚡ Real-time API Integration
- 📱 Responsive User Interface

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Axios
- Bootstrap 5
- HTML5
- CSS3

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/Priyank1922/Pagination_Frontend.git
```

## 2. Navigate to the Project

```bash
cd Pagination_Frontend
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Configure Backend URL

Make sure the backend server is running.

Default Backend URL:

```text
http://localhost:8080
```

If required, update the Axios Base URL inside your API service.

Example:

```javascript
const BASE_URL = "http://localhost:8080/api";
```

## 5. Run the Application

```bash
npm start
```

The application will start at:

```text
http://localhost:3000
```
